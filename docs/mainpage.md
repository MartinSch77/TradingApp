# TradingApp developer documentation {#mainpage}

Qt 6 desktop app that trades instruments via the official eToro Public API,
with a consolidated multi-source decision system (technical ensemble,
TradingView rating, news sentiment, VIX regime, CNN Fear & Greed crowd
sentiment, optional Claude synthesis), a costed trade planner, and full
cost/fee accounting.

## Traceability tags

Test functions carry structured tags that the trace tool machine-reads:

    //! @tstid TS-PLAN-004 @design DES-DOM-PLAN
    // @relation(REQ-F-011, scope=function)

The `@relation(REQ-…, scope=function)` line is a StrictDoc source-coverage
marker — the same marker feeds both the traceability matrix and the StrictDoc
requirement ↔ source view (`tools/make_requirements.sh`).

`requirements/requirements.sdoc` defines REQ ids (single source of truth;
`docs/requirements.md` is generated from it), `docs/design.md` maps DES elements to
implementing classes and the requirements they satisfy, `docs/test_spec.md`
specifies the TS cases, `tests/tst_*.cpp` implement them 1:1, and
`test-results/*.xml` (JUnit, written by `tools/run_tests.sh`) carry the
verdicts. `tools/trace_report.py` renders the joined matrix and lists every
gap explicitly.

@warning Trading CFDs with leverage risks your capital. Everything this app
computes — probabilities, plans, forecasts — is a model estimate for decision
support, never a guarantee.
