# Traceability standards for downstream projects

This directory defines the common minimum traceability record expected in any project reusing the TradingApp reference process.

## Required chain

Feature → Requirement → Design Element → Implementation → Verification → Evidence → Human approval

## Required minimum fields

Each item must record:
- ID
- title
- owner
- status
- parent reference
- child reference(s)
- verification method
- evidence reference
- approver
- approval date

## Project rule

A project is not release-ready unless a traceability report can be generated from these records and shows no hard gaps.
